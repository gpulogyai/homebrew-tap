# GPULogy Homebrew Tap

```sh
brew tap gpulogyai/tap
brew install --cask letthembuild
```

Installs the [LetThemBuild](https://letthembuild.com) desktop app and its
`ltb` command line. Claude, ChatGPT, Gemini and Grok build and review each
other's work in your checkout — and run the commands to prove it.
